# LeetCode 2235 – Add Two Integers

**Difficulty:** Easy  
**Language:** Java  
**Topics:** Variables, Integers, Arithmetic Operators, Methods

## Problem

Given two integers `num1` and `num2`, return their sum.

## Java Solution

```java
class Solution {
    public int sum(int num1, int num2) {
        return num1 + num2;
    }
}
```

## Example

**Input:**
```text
num1 = 12
num2 = 5
```

**Output:**
```text
17
```

**Explanation:**

Add both integers:

12 + 5 = 17

## Logic – Step by Step

1. Receive two integers: `num1` and `num2`.
2. Use the `+` operator to add them.
3. Return the result.

## Important Java Concepts

- `int` – stores whole numbers.
- `+` – performs addition.
- `return` – sends the calculated result back.

## Complexity

- **Time Complexity:** O(1)
- **Space Complexity:** O(1)

## One-Line Logic

Add the two given integers using the `+` operator and return the sum.
